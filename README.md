AI Content Generator

AI Content Generator is a web-based application that generates high-quality blog content using artificial intelligence.

Features
- Generate blog content from user input (topic, keywords, tone)
- SEO-friendly structured output
- Simple and user-friendly interface
- Fast and automated content creation

Tech Skills
- Frontend: (HTML, CSS, JavaScript)
- Backend: (Python / Flask or Django)
- Version Control: Git & GitHub

 Workflow
- Feature-based development using Git branches
- Code collaboration through Pull Requests (PR)
- Task management using ClickUp
